1) Выбор фреймворка и описание решения
	В результате анализа проекта пришел к выводу что существует 3 основных домена:
 	- Авторизация (auth)
	- Работа с профилем (users)
	- Работа с карточками фотографий (cards)
	Все это объеденено на одной главной старнице.
	Работа всех разделов с backend частью просиходит при помощи REST API.
	Т.к. проект не очень большой использование различных фреймворков для разных микрофронтендов считаю не целесообразно.
	Поэтому для разделения монолитной части фронтенда будем применен фреймворк Webpack Module Federation, т.к. в качестве дополнительного плюса можно использовать его возможности динамического обмена зависимостями shared dependencies.
	Т.к. большинство файнкций фронтенда требует взяимодействия с backend часть, логично для настройки межпроцессорного взаимоействия использовать взаимодейсвие на основе API. В будущем возможно создание BFF для каждого микрофронтенда для увеличения гибкости.
	Схема взаимодействия в графическом виде представлена в файле mesto.drawio в корне проекта.
	https://github.com/andrey16100/architecture-sprint-1/blob/mesto/mesto.drawio
